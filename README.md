# 📡 Primerica Operations Hub

A fully client-side operations dashboard for call center analytics, agent adherence tracking, and attendance reporting. Runs entirely in the browser — no server required.

**Live Dashboard → [jeremyacd.github.io/OPs-Dashboard](https://jeremyacd.github.io/OPs-Dashboard/)**

---

## 📋 What It Does

### 📞 Operations Tab
- Inbound/outbound call volume, answered, abandoned, transferred, denied
- Hourly charts: Calls, Transfers, Denied Calls, AHT
- Queue-level breakdown table with SL%, ASA, AHT, abandon rate
- Agent Performance table with Clock In/Out, Adherence %, and call metrics
- IVR pre-queue activity section
- Spanish language queue section
- Chat support section
- Staffing by hour (requires User State Detail upload)

### ⏱ Adherence Tab
- **Day view** — per-agent row with Clock In, Clock Out, Lunch time, Adherence %, and per-policy columns (Break, Lunch, ACW, CB, Setup)
- **Week view** — calendar grid, one cell per day, color-coded adherence with mini violation tags
- **Month view** — summary row per agent with violation counts for every policy category
- Absence/status tagging (PTO, FMLA, Excused, Unexcused, Bereavement, Jury Duty, etc.)
- Filter by adherence tier, clock status, agent name

### 📊 State Detail Tab (per agent)
Accessed by clicking any agent name → **📊 State Detail** tab:
- Summary cards for every state type with total minutes and % of shift
- Per-day breakdown table: Clock In/Out, Lunch, and a column for every state
- Totals row with cumulative minutes and percentages
- Respects Day / Week / Month view filter

## 🚀 Admin Workflow — Publishing Data

Data is pre-loaded for all viewers. **Only the admin needs to upload CSVs.**

### Step 1 — Load your data locally
Open `index.html` in your browser and upload:
- **📞 CDR Report** — Call Detail Record CSV export
- **📅 Schedule CSV(s)** — Weekly Data Export files (select multiple for a full month)
- **👤 User State Detail** — Actual worked time & state data CSV

### Step 2 — Publish
Once all files are loaded, click the **📤 Publish Data** button in the header.
This downloads `dashboard-data.json` to your computer.

### Step 3 — Commit to GitHub
Upload `dashboard-data.json` to the root of this repo (same folder as `index.html`) and commit.

### Step 4 — Everyone sees it
Anyone visiting the dashboard URL will automatically see your published data — no uploading needed on their end. A green **"Live data · Published by administrator"** banner confirms data is loaded.

> **To refresh the data:** repeat Steps 1–3 with new CSVs. The dashboard always fetches fresh on page load.

## ✅ Adherence Policy Thresholds

Adherence is calculated as:
```
Adherence % = (Scheduled Minutes − Total Violation Minutes) / Scheduled Minutes × 100
```

| Policy | Limit | Notes |
|---|---|---|
| Break | 10 min max per instance | Max 2 breaks per shift; 3rd+ break = full violation |
| Lunch | 30 min max | 1 per shift |
| Additional Call Wrap | 2 min max | Any overage is a violation |
| Outbound Callback | 3 min max | Any overage is a violation |
| System Setup | 5 min total max | |
| NOT READY - Please Go Available | 2 min total max | |
| Clock-In (late or early) | ±1 min tolerance | Any deviation beyond 1 min reduces adherence |
| Clock-Out (late or early) | ±1 min tolerance | Any deviation beyond 1 min reduces adherence |

**Clock-In** is defined as the agent's first **"NOT READY - Please Go Available"** state of the day.  
**Clock-Out** is defined as the end time of the agent's last state of the day.

## 📤 Input File Formats

### CDR Report
Standard call detail export with columns including:
`Master Session ID, Direction, Channel Type, Queue, User, Talk Time, Handle Time, Queue Time, Wrap Time, Completion Code, Answered In SLA, Callbacks (Requested), Denied (Previously), Date / Time`

### Schedule CSV
Weekly export with agent names in the first column and date columns as headers:
```
Agent Name | Sunday 01 Mar 2026 | Monday 02 Mar 2026 | ...
Anders, Devon | | 09:00 AM-05:30 PM | ...
```
Select multiple weekly files at once to cover a full month.

### User State Detail
State-by-state log with columns:
`User Name, State Name, State Attributes, Start Time, End Time, State Duration, Queue, Channel Type`
