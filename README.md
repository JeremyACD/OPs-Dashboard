# 📡 Primerica Operations Hub

A fully client-side call center operations dashboard for CDR analytics, agent adherence tracking, attendance reporting, and staffing visibility. Runs entirely in the browser — no server, no login, no installation required.

**Live Dashboard → [jeremyacd.github.io/OPs-Dashboard](https://jeremyacd.github.io/OPs-Dashboard/)**

## 🚀 Admin Workflow — Publishing Data

Only the admin needs to upload CSVs. Everyone else sees the data automatically.

### Step 1 — Load your data locally
Download `index.html` from the repo and open it in Chrome. Upload your files using the buttons in the header:

- **📞 CDR Report** — Call Detail Record CSV export (single file)
- **📅 Schedule CSV(s)** — Weekly Data Export files. Hold **Ctrl** (Windows) or **Cmd** (Mac) when selecting to load multiple weeks at once
- **👤 User State Detail** — Actual worked time and state data. Hold **Ctrl/Cmd** to select multiple files if your state export is split across date ranges — they will be merged automatically

### Step 2 — Publish
Once all files are loaded, click the **📤 Publish Data** button in the header. This downloads `dashboard-data.json` to your computer.

### Step 3 — Commit to GitHub
Go to the repo → **Add file → Upload files** → drop in the new `dashboard-data.json` → **Commit changes**. GitHub automatically replaces the old file since the filename is the same.

### Step 4 — Everyone sees it
Anyone visiting the dashboard URL will automatically see your published data — no uploading needed on their end. A green **"Live data · Published by administrator"** banner confirms data loaded successfully.

> **To refresh the data:** repeat Steps 1–3 with new CSVs any time you want to update.

## 🔍 Views & Filters

The dashboard supports five view modes, selectable from the top control bar:

| View | What it shows | Date Control |
|---|---|---|
| **Day** | Single date — every metric for that day | Date picker |
| **Week** | 7-day rolling window | ‹ › navigation arrows |
| **Month** | Full calendar month | Date picker (month/year) |
| **Quarter** | Full fiscal quarter (Q1–Q4) | Quarter + Year dropdowns |

When you switch to **Quarter** view, the dashboard automatically defaults to the current quarter and year. Use the dropdowns to navigate to any prior quarter for historical reporting.

All metrics, charts, queue tables, staffing by hour, agent performance, and adherence data respond to the selected view. The **Export** button always downloads data matching your current view and any active filters.

## ⬇ Export

The **Export** button downloads a CSV of whatever you are currently viewing, respecting your active view (Day / Week / Month / Quarter) and any filters applied.

### Operations Tab Export
Downloads `agent_performance_[period].csv` — one row per agent with:
- Answered, Transferred, Outbound, Callbacks, Denied
- Avg Talk, AHT, ASA, Avg Wrap, SL%
- Adherence %, Days Worked, Days Scheduled

### Adherence Tab Export
Downloads `adherence_[period].csv` — one row per agent per day with:
- Schedule, Clock In, Clock Out, Lunch
- Adherence %
- Total Violation Minutes
- Individual violation columns: Break Excess, Lunch Excess, ACW Excess, CB Excess, Setup Excess, NR Excess, Late/Early In, Early/Late Out
- Status tag (PTO, FMLA, etc. if marked)

The filename automatically reflects the period — for example `adherence_Q1_2026.csv` or `agent_performance_2026-03.csv`.

> **Tip:** Filter by agent, adherence tier, or clock status before exporting to get a targeted subset.

## ⏱ Adherence Tab

### Views
- **Day** — per-agent row with Clock In, Clock Out, Lunch time, Adherence %, and per-policy columns
- **Week** — calendar grid with one cell per day, color-coded adherence and mini violation tags
- **Month** — summary row per agent with violation counts for every policy category
- **Quarter** — same as Month view, aggregated across the full quarter

### Adherence Formula
```
Adherence % = (Scheduled Minutes − Total Violation Minutes) / Scheduled Minutes × 100
```

Every minute over any policy limit is deducted directly from adherence.

### Policy Thresholds

| Policy | Limit | Notes |
|---|---|---|
| Break | 10 min max per instance | Max 2 breaks per shift — 3rd+ break is a full violation |
| Lunch | 30 min max | 1 per shift |
| Additional Call Wrap | 2 min total max | Any overage is a violation |
| Outbound Callback | 3 min total max | Any overage is a violation |
| System Setup | 5 min total max | |
| NOT READY - Please Go Available | 2 min total max | |
| Clock-In (late or early) | ±1 min tolerance | Every minute beyond 1 min reduces adherence |
| Clock-Out (late or early) | ±1 min tolerance | Every minute beyond 1 min reduces adherence |

### Clock-In / Clock-Out Definition
- **Clock-In** = start time of the agent's first **"NOT READY - Please Go Available"** state of the day
- **Clock-Out** = end time of the agent's **last state** of the day

### Filters
- Filter by adherence tier (≥90%, 75–89%, 50–74%, <50%, No Activity)
- Filter by clock status (Late Clock-In, Early Clock-In, Left Early, Stayed Late, On Time)
- Search by agent name

### Absence / Status Tagging
Click any day cell or agent row to mark: PTO, FMLA, Excused Absence, Unexcused Absence, Late Arrival, Left Early, Bereavement, Jury Duty

## 📊 Queue Abandon % — Calculation Rules

Queue Abandon % only counts **true abandons**:
- Call reached an agent queue (not IVR)
- Customer abandoned with code `Abandoned`
- Customer waited **≥ 60 seconds** before hanging up

Short hangups under 60 seconds and IVR abandonments are excluded from the abandon count and percentage everywhere in the dashboard.

## 📂 Input File Formats

### CDR Report
Standard call detail export. Required columns include:
`Direction, Channel Type, Queue, User, Talk Time, Handle Time, Queue Time, Wrap Time, Completion Code, Answered In SLA, Callbacks (Requested), Denied (Previously), Forwarded, Transfer Time, Date / Time`

### Schedule CSV
Weekly export — agent names in column 1, date columns as headers:
```
Agent Name | Sunday 01 Mar 2026 | Monday 02 Mar 2026 | ...
Anders, Devon | | 09:00 AM-05:30 PM | ...
```
Select multiple weekly files at once (Ctrl/Cmd+click) to load a full month or quarter.

### User State Detail
State-by-state activity log. Required columns:
`User Name, State Name, State Attributes, Start Time, End Time, State Duration, Queue, Channel Type`

If your state data is split across multiple exports (e.g. different date ranges), select all files at once — the dashboard merges them automatically.

## 🛠 Technical Notes

- Runs entirely client-side — no backend, no database, no cookies
- All data stays in the browser; nothing is sent to any external server
- Compatible with Chrome and Edge; best viewed on a widescreen monitor
- Data is compressed with LZ-String before publishing to keep file sizes small
- Published data auto-loads on page open; if data was built with an older version of the dashboard a red warning banner will prompt the admin to re-publish
